# Lukas Beeckman | Portafolio visual

App web en React/Vite para presentar el catálogo de obra de Lukas Beeckman como portafolio artístico, archivo visual y experiencia de galería digital.

## Uso local

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

La carpeta `dist/` contiene la versión lista para publicar en hosting estático.

## Estructura curatorial

- `src/data/artworks.js`: datos de las 26 obras, etiquetas, series, notas curatoriales e imágenes.
- `public/artworks/`: láminas visuales y páginas renderizadas del catálogo.
- `src/main.jsx`: componentes de hero, galería, filtros, recorrido visual, archivo, contacto y ficha ampliada.
- `src/styles.css`: sistema visual, responsive y efectos 3D sutiles.
